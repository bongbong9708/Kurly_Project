## AI 응답 요약

- 설계 선택지 3개 제시, 각각 추천안 표시
  1. 개별 삭제 UI: 행 오른쪽 `x` 버튼 (추천) vs 밀어서 삭제(`.onDelete`)
  2. 삭제 대상 식별: `keyword` (추천) vs `UUID` id 추가
  3. 전체 삭제 확인 창: 없음 (추천) vs 확인 알림
- 가정 명시: "전체삭제"는 Section footer 오른쪽, 목록이 비면 숨김, 개별 삭제는 저장된 표기 그대로(대소문자 구분) 찾음
- 테스트 먼저 작성 → 컴파일 실패 확인 → 구현
  - UseCase: `delete(keyword:)`, `deleteAll()` (전체 삭제는 `save([])`)
  - ViewModel: `delete(keyword:)`, `deleteAll()` 후 `recentSearches` 갱신
- `x` 버튼에 `.buttonStyle(.borderless)` 적용
  - List 행 안의 버튼은 기본적으로 행 전체 탭에 반응한다. #7에서 행 탭을 검색에 쓰므로 버튼 영역만 반응하게 함
- 아이콘만 있는 버튼이라 VoiceOver용 `accessibilityLabel` 추가
