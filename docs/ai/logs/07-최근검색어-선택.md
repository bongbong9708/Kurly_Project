# 07. 최근 검색어 선택 시 검색 실행 (Issue #7, PR #23)

## 목표

최근 검색어를 탭하면 그 키워드로 검색 결과를 보여준다.
선택한 검색어도 저장 시각이 갱신되어 목록 맨 위로 올라온다.

## AI 응답 요약

- 설계 선택지 2개 제시, 각각 추천안 표시
  1. ViewModel 진입점: `search(keyword:)` 추가 (추천) vs View에서 `query` 설정 후 `search()` 호출
  2. 선택 시 검색바: `.searchable(isPresented:)`로 활성화해 "취소" 버튼 표시 (추천) vs 활성화 안 함
- 가정 명시: 검색바를 활성화하면 키보드가 올라올 수 있으니 내리는 쪽으로 처리하겠다
- 테스트 2개 먼저 작성 → 컴파일 실패 확인 → 구현
  - VM 테스트의 UseCase에 1초씩 흐르는 시계를 주입 (연달아 저장해도 시각이 겹치지 않게)
- 행의 글자 영역을 `Button`으로 감싸 탭하면 검색. `x` 버튼은 #5의 `.borderless`로 분리되어 있어 간섭 없음
- **첫 구현에서 행 글자가 파란색으로 보임**
  - `.foregroundStyle(.primary)`를 줬지만 버튼 안에서는 `.primary`가 강조색을 가리킴
  - 시뮬레이터 확인으로 발견 → `Color.primary`로 수정
- **가정이 틀림: iOS 17에서는 키보드를 깔끔하게 내릴 API가 없음**
  - 검색바를 활성화하면 키보드가 올라와 결과를 가림. `.searchFocused`는 iOS 18+
  - 선택지 제시: A 키보드 유지 / B UIKit `resignFirstResponder` / C iOS 18+만 `.searchFocused` / D 활성화 취소
- 같은 원인으로 #5의 `x` 아이콘이 회색이 아니라 강조색으로 보인다는 점을 알림 (수정하지 않음)
