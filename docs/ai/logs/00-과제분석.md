## AI 응답 요약
- 과제 원문 이미지 7장과 채용 공고 본문을 읽고, 기존 CLAUDE.md 체크리스트가 원문과 일치함을 확인
- 과제에서 나온 항목(평가 기준 누락분, 예시 화면에서 읽히는 UI, 해석이 갈리는 요구사항 6개)을 정리. 공고에서 얻은 포지션 맥락은 공개 정보로 분류
- 기술 스택·최소 iOS·시작일 등 설계 판단은 채우지 않고 선택지로 제시
- 진행 가이드: 0일차 셋업 → 검색 화면 → 결과 화면 → 추가 구현 → 문서 정리 순서 제안
- SwiftUI + Clean Architecture 결정 후: UseCase 3안 제시 (A. 로직 있는 곳만 / B. 전부 / C. 생략), A 권장. 이 앱 규모에서 위임만 하는 UseCase는 과하다고 지적
- 레이어는 폴더 구분으로 시작하고 모듈화는 기본 요구사항 이후 검토하자고 제안
- 커밋 메시지 형식은 위임받아 기존 초안 `[#이슈] 타입: 내용`에 타입 목록(feat/fix/refactor/test/docs/chore)을 채움
- CLAUDE.md를 Public 레포에 넣으면 과제 요구사항 요약이 함께 공개된다는 충돌을 지적 → 과제에서 나온 내용은 `과제내용/요구사항정리.md`(gitignore)로 분리하고, CLAUDE.md에는 작업 원칙·설계 결정만 남기는 안을 적용
- 최소 iOS: App Store에서 카카오톡·컬리 앱 모두 iOS 17.0 이상임을 확인. iOS 26으로 얻는 건 사실상 SwiftUI 네이티브 WebView뿐이라고 지적하고 17 vs 26 트레이드오프 제시
